# 合租生活管家 HomeMate 🏠

> 面向合租宿舍的轻量协作面板：让所有室友共享同一份「账本 + 排班表 + 物品清单 + 公约」，用信息透明化解合租矛盾。

**在线访问**：https://xd0122.github.io/homemate-butler/

## 一、背景与痛点拆解

| 痛点 | 场景表现 | 衍生需求 | 对应模块 |
|------|---------|---------|---------|
| 💸 费用算不清 | 垫付后口算扯皮，谁付了、谁欠谁无依据 | 自动分摊、每人实时应收/应付、**结清留痕**、凭证可追溯 | 费用分摊 |
| 🧹 值日排班混乱 | 微信群排班刷屏就忘，做没做没人知道 | 日历化呈现、按天查看任务详情、打卡、自动轮值 | 值日日历 |
| 📦 公共物品没人管 | 用完才发现没了，谁买的剩多少是糊涂账 | 库存动态、消耗/补货留痕、低于提醒线自动预警 | 公共物品 |
| 📜 口头约定无据 | 说过就忘，矛盾时各执一词 | 公约上墙、全员逐条确认留名 | 室友公约 |

**核心洞察**：合租矛盾的根源不是「人坏」，而是**信息不透明 + 责任无留痕**。所以产品的每一处设计都围绕「可查、可溯、可确认」。

## 二、功能设计

### 💰 费用 AA 分摊
- 记账（项目/金额/垫付人/日期）+ 自动按人均摊
- **实时应收/应付**：仅统计未结清账单，并给出「谁转给谁多少」的转账建议
- **结清机制**：勾选即结清 → 自动转入已结清、同步更新月账单明细与余额数据，记录确认人
- **发票/凭证上传**：图片自动压缩存储，点开可查大图，费用透明可追溯
- **月账单明细**：按月归档，每月展示总支出 / 已结清 / 未结清三组数据

### 🧹 值日日历
- 月历视图呈现排班，**点开任意日期**查看当天每项任务、负责人、完成状态
- 格子上直接显示「任务·负责人」芯片（橙=待完成，绿=已完成）
- 一键生成本月轮值（成员轮转 × 任务轮转），杜绝排班真空

### 📦 公共物品登记
- 登记字段：名称 / 类别 / 购买人 / 数量+单位 / 提醒线
- 库存进度条 + 三级状态（充足 / 偏低 / 需补货），低于提醒线自动聚合预警
- **补货 / 消耗**操作留痕：谁操作、加减多少、备注、时间
- 按类别筛选

### 📜 室友公约
- 条目管理 + 以当前身份逐条「确认遵守」留名

## 三、多人同步架构（重点）

合租数据**属于房间而不属于个人**，产品以「房间码」为数据容器：

1. **房间码机制**：每个寝室一个 4-6 位房间码，室友输入房间码即进入同一份数据；身份选择器区分操作人，操作动态记录「谁做的」
2. **本地优先 + 云端通道**：
   - 本地模式：数据存浏览器，同浏览器多标签页通过 BroadcastChannel **实时同步**（可现场演示多人协作）
   - 云同步模式：同步引擎实现标准 REST 接口 `GET/PUT /api/room/:code`（4s 轮询 + 变更推送，Last-Write-Wins 冲突策略），配套的 Node 同步服务器见 `server.js`，部署后前端**零改动**即启用跨设备/跨室友实时同步
3. 访问已部署的后端版（或任意 URL 加 `?api=<同步服务器地址>`）即可开启云同步

## 四、技术说明

- 纯前端单页应用（HTML + CSS + 原生 JS），零依赖；凭证图片 canvas 压缩后本地存储
- 同步服务器：Node 原生 http，JSON 文件持久化，支持 CORS，无第三方依赖
- 部署：GitHub Pages（静态托管）
