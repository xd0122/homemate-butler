# 合租生活管家 HomeMate 🏠

面向合租宿舍的轻量协作面板，让所有室友共享同一份「账本 + 排班表 + 物品清单 + 公约」，用信息透明化解合租矛盾。

## 核心痛点

- 房租水电分摊不清
- 公共区域清洁排班混乱
- 共用物品消耗无记录
- 口头约定无据可查

## 功能模块

| 模块 | 功能 |
|------|------|
| 💰 费用 AA 分摊 | 记账、自动按人均摊、显示每人应收/应付 |
| 🧹 清洁值日排班 | 每周轮值表 + 完成打卡留痕 |
| 📦 公共物品登记 | 购买人、余量状态、自动补货提醒 |
| 📜 室友公约 | 条目管理 + 全员「确认遵守」 |

## 技术说明

- 纯前端单页应用（HTML + CSS + 原生 JS），零依赖
- 数据保存在浏览器 localStorage，内置示例数据
- 部署方式：GitHub Pages（静态托管）
